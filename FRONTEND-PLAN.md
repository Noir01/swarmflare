Cookie Secure/HttpOnly/SameSite; same-origin+CSRF for cookie writes. Public catalog/source responses never expose email/password/session/token hashes, private cloud configuration or existing demo state. API base /api/platform: /auth/signup {username,email,password}, /auth/login {login,password}, /auth/session GET {user,csrf,expiresAt}, /auth/logout POST; /repos GET {repositories}; /repos POST {name,description,initializeReadme,importUrl?}; /repos/:owner/:name GET {repository}; /repos/:owner/:name/source?path=... Repo metadata includes id,owner,ownerId,name,description,projectId,status,source identity (when verified), createdAt. Failed/pending provisioning is honest and cannot be treated as source-ready.
