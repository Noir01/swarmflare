## Shared contracts and ownership
New bounded Platform SQLite DO stores unique accounts, PBKDF2 salted password hashes, opaque revocable session hashes+CSRF, public repo catalog and authenticated owner IDs, per-repo projectId/Artifacts repository mapping and hashed scoped agent grants. Cookie Secure/HttpOnly/SameSite; same-origin+CSRF for cookie writes. Public catalog/source responses never expose email/password/session/token hashes, private cloud configuration or existing demo state. Agent tokens are owner-issued, repository-scoped contributor/reviewer only (never human/runner); raw token returned once privately, absent from public guide/URLs. Account owner may administer only their repositories. Existing Project acceptance/review/source identity checks stay authoritative, not reimplemented or weakened.

API base /api/platform: /auth/signup {username,email,password}, /auth/login {login,password}, /auth/session GET {user,csrf,expiresAt}, /auth/logout POST; /repos GET {repositories}; /repos POST {name,description,initializeReadme,importUrl?}; /repos/:owner/:name GET {repository}; /repos/:owner/:name/source?path=... GET {commitOid,treeOid,entries,file?,readme?}; /repos/:owner/:name/agents POST {role,expiresInSeconds} and grants read/revoke. Errors {code,message}, no secrets or provider responses. Repo metadata includes id,owner,ownerId,name,description,projectId,status,source identity (when verified), createdAt. Failed/pending provisioning is honest and cannot be treated as source-ready.

Storage seam: new bounded repository-source module uses actual Artifacts binding create/get/info, existing transport pack/object functions and scoped temporary read/write token cleanup. Support empty or README-initialized repositories and restricted public HTTPS import ONLY from verified canonical GitHub public owner/repo URLs (no credentials/ports/query/fragments/IPs/redirects/SSH/local sources/submodule execution). Bound transfer, object/tree/file sizes and time; never execute imported source. Verify source tuple/readback before marking ready. No cloud tokens browser-side. If binding/import capability cannot be exercised, expose specific unavailable status, not simulated success.
