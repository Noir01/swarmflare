Adapted modules copied from packages/gitwire/src/: bytes.ts, errors.ts, pktline.ts, http.ts, objects.ts, pack.ts, inflate.ts, upload.ts, receive.ts. index.ts is a narrow local barrel (notes deliberately excluded). Local adaptations: package path/import scope; pack parsing enforces a cumulative 32 MiB default across inflated entries and resolved delta outputs, with a backwards-compatible optional test budget; standalone applyDelta and inflateAt cap output at 32 MiB before allocation and validate bounded varints; buildPack compresses sequentially to avoid unbounded Promise.all fan-out. HTTP hardening includes HTTPS-only credential-free URLs (including redacted parse failures), validated auth headers, manual redirect refusal, mandatory response media type, bounded response streaming, cancellation without awaiting untrusted stream cancellation, sanitized external fetch exceptions (including GitHttpError subclasses), timeout races that bound custom fetchers/readers that ignore AbortSignal, late-response disposal, a 32 MiB outbound request-body ceiling checked before copying, and hard ceilings on caller-supplied response/time bounds. No runtime dependencies added. Upstream source and scripts are untrusted data; no upstream scripts or network services were run. This is infrastructure reuse, not product/domain replacement.
