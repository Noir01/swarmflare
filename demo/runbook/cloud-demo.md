Run the bounded local service in a foreground terminal using `node --import tsx apps/local/index.ts --state <protected-directory> --port 0 --run-seconds 1800`. Provide `AUTH_CREDENTIALS` and `DASHBOARD_SESSION_KEY` through its environment, not command arguments. It binds to loopback, expires after the requested duration (maximum 1800 seconds), and can be stopped with Ctrl-C. See `demo/runbook/local.md` for isolation details. The old service URL/token are not reusable. This is local Miniflare, not a Cloudflare service.

For one-shot runner operations, see `demo/runbook/runner.md`; it documents the exact `source-job`, `mandatory-checks`, `verify-source`, and `review-artifact` JSON argument forms and runner-only environment. Local runner URLs must be loopback and Git paths local. Do not run both commands and demos against valuable state; select a disposable workspace. `apps/setup/index.ts --help` documents local-only metadata setup and its required seed commit/tree. Setup alone does not publish the seed or make a runnable baseline.

The CLI supports the commands listed by `node --import tsx apps/cli/index.ts --help` (including context, claims, decisions, revisions, Views, findings, checks, readiness, reviews, feedback/repair, and separate human-only acceptance commands). Use the live API/dashboard state and current CLI help; do not copy old IDs or payloads from reports. The CLI allows a bounded request count/deadline, not an autonomous session.

Do not accept on the operator's behalf; acceptance changes a local baseline, not a deployment. State plainly if no human decision occurred.
7. **Close (30 sec):** report exact commands/tests and outcomes, what was local versus cloud, what was not recorded, and remaining qualification/publication gates.
