# Local preview prerequisites

The local browser preview requires Node.js and a Chromium/Chrome-for-Testing executable named `chromium` on `PATH`. The launcher searches only absolute PATH directories, skips empty and relative entries, and accepts only a resolvable executable regular file; it does not search a user home directory or accept an arbitrary command override. There is no download or `--no-sandbox` fallback. If Chromium is missing, have the machine operator install it through the normal package-management process and put its executable directory on `PATH`.

This repository's preview/test suite is not general cross-platform or Node-only. The verified host is Linux/NixOS with `/nix/store` access, bubblewrap (`bwrap`), `fc-match` and a usable sans-serif font, Linux `/proc` cgroup visibility, and working user namespaces/bubblewrap isolation. The sandboxed Node check also expects Node in `/nix/store`. These are operator-installed/runtime prerequisites; a worker does not perform global setup. Do not infer portability to macOS, Windows, or arbitrary Linux distributions.

For a source checkout, `npm ci --offline` succeeds only if all pinned dependencies are already cached; otherwise ordinary `npm ci` needs dependency access arranged by the operator. With dependencies installed, use `node --import tsx ./node_modules/vitest/vitest.mjs run --config vitest.config.ts tests/browser/executable.test.ts tests/browser/local-browser.test.ts`. A clean archive/checkout needs testing on the target host; source packaging does not provide Chromium or isolation prerequisites. Continuous26 full regression log: `reports/evaluation/continuous26-final-regression.log` (70 unit/local files, 265 tests; 28 Worker files, 96 tests). These are host-specific, not cross-platform validation.
