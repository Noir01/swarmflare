# Foundation smoke qualification (operator-only)

This helper is a synthetic-account, bounded, one-shot qualification for the created README repository. It prepares the generated task contract, its generated mandatory policy, and the first verified source baseline. It does not accept a candidate, execute imported code, create checks/reviews/readiness, alter the legacy imported repository, or confirm a human decision.

The helper reads `.local/cloud-cont40/platform-smoke-private.json` only when the operator explicitly executes it. It validates the synthetic-only username/email and the exact ready repository/source tuple against `reports/evaluation/continuous40-platform-smoke.json` before login. Never run it with human credentials, edit or replace the original private file, or inspect/report its contents. A separate `.local/cloud-cont46/foundation-private.json` is created owner-only for resumable session/CSRF/request IDs; the sanitized report is `reports/evaluation/continuous46-native-foundation.json`.

Execution requires separate parent authorization. Do not run during local qualification. From repository root, an authorized operator may execute:

`node --import tsx demo/cloud/foundation-smoke.ts`

Every request is to the fixed C29 origin, refuses redirects, times out at 20 seconds, and shares a 25-request budget. Resource conflicts stop rather than overwrite. Request IDs are durably reserved before their corresponding writes. The helper verifies logout and reads back the contract, policy, baseline and unchanged repository source. Reports include safe status/code and nonsecret resource/source provenance only.

Observed interfaces reflected by the helper: non-`/api/` platform endpoints are rooted under `/api/platform`; direct project and other `/api/` routes retain their path. Contract approval returns HTTP201 with the approved contract resource, and the original proposal is read back as approved. Baseline initialization returns `{status:'initialized', baseline, job}`; the baseline receipt uses an immutable `refs/agent/seeds/<seedId>` ref. The completed seed job, its exact source/receipt and the subsequent baseline readback must agree. Policy is compared as the complete `{contractVersion, ...policyTemplate}` value, recursively ignoring object key order only. Existing resources are accepted only when their values match the generated fixture/version/source; otherwise the helper fails closed. Request IDs are persisted before writes to permit safe idempotent replay, and authenticated execution attempts logout in cleanup even after failure. The original private fixture file is never written and is byte-compared before reporting success. The persisted cache excludes synthetic password/username/email and contains only session/CSRF material and request IDs.

Native qualification completed20 requests: validated synthetic login/session, generated proposal and approval, policy configuration, actual Artifacts seed publication and exact baseline/readback, unchanged original source and logout. A matching rerun completed16 requests with no resource writes, confirming resumability rather than duplicating proposals or initialization. These counts concern the bounded synthetic fixture, not the reserved human account. Tests use injected synthetic fetches; they are not the native proof. Native foundations are qualified, while native candidate publication/composition/checks/repair, actual agent review and real human confirmation/acceptance remain outstanding. `prepared-metadata-only` labels that narrow scope; it does not deny that initialization actually published/read back a Git seed.
